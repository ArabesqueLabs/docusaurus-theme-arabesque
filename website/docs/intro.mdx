Arabesque is a Docusaurus theme built on the [Arabesque design system](https://github.com/ArabesqueLabs/design-system), the system [arabesquelabs.com](https://arabesquelabs.com) is made with. It restyles the classic theme with the system's tokens, type and components, so a documentation site looks and reads like the rest of Arabesque.

This version of the theme is built on **design system 0.8.0**.
